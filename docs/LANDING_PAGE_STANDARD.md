# Moorvio landing-page conversion standard

Status: **draft implementation for review**, November 7, 2026. The ten sections below are used in the proposed public Moorvio homepage and should be adapted per brand, never copied as interchangeable marketing filler.

1. **Hero** — specific offer, distinctive relevant visual and primary action.
2. **Social proof** — use only verified customers, endorsements, usage counts or evidence; where none exists, state the project facts without fabricated logos or statistics.
3. **Problem** — describe the visitor's real frustration.
4. **Solution** — show the concrete transformation and value.
5. **Features** — concise, outcome-oriented, with development/availability status.
6. **How it works** — three to four practical actions.
7. **Testimonials** — verified consented quotes only, or a transparent unfilled pilot-feedback section.
8. **Pricing** — actual published plans; if unfinalized, disclose the access status. Never invent offers.
9. **FAQ** — answer friction, delivery, availability, security and billing accurately.
10. **Final CTA** — one primary next step, with no pretend checkout or waitlist.

## Visual system
- Dark electric-navy foundation with cyan, lime, lilac and restrained coral accents.
- Expressive, accessible display hierarchy; custom CSS workflow illustrations, editorial split sections, timeline and open typographic rhythm instead of repetitive cards.
- Responsive layouts, keyboard focus, semantic sections, accessible native FAQ details and reduced-motion support.
- Performance first: no external font/CDN, third-party scripts, tracking pixels, auto-playing assets, forms or paid API dependencies.

## Publication gates
- Review at mobile, tablet and desktop widths and keyboard-only interaction.
- Validate each CTA destination and factual claim.
- Confirm accessibility, SEO metadata and no fake testimonials or subscriptions.
- No main-branch merge, publishing, domain, account, subscription, or billing changes without explicit go-live authorization.
- Private Moorvio app, CRM logic and permissions are unaffected.
